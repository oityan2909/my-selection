MY SELECT - 美容・スキンケアサイト

内容
- index.html: トップページ（カテゴリ絞り込み機能付き）
- guide-*.html: スキンケア記事6本
- about.html: 運営者情報
- privacy.html: プライバシーポリシー
- disclaimer.html: 免責事項
- style.css: 共通デザイン

公開前に必ず行うこと
1. about.html の運営者情報・問い合わせ先を実際の内容に変更。
2. Amazonアソシエイトに登録し、承認後に各商品に対応した専用リンクへ差し替える。
3. 商品を紹介する記事は、自分で確認した商品情報・使用経験・比較基準を加えて独自性を持たせる。使用していない商品を使用したように書かない。
4. プライバシーポリシーのアクセス解析・Cookie欄を、実際に導入するサービスに合わせて修正。
5. サイト全体をHTTPSで公開し、スマホ表示・リンク切れを確認。
6. Amazonの最新の参加要件、リンク表示、価格・画像の利用条件を公式規約で確認。

注意
このパッケージは公開用の静的サイトのたたき台です。Amazonアソシエイトの承認を保証するものではありません。Amazonの画像・価格・評価等を無断で転載せず、公式に認められた方法・素材のみ使用してください。
